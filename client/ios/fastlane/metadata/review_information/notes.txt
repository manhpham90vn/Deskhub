Deskhub provides remote desktop, terminal and file transfer for a computer the user owns or is authorized to access. The iOS client connects directly over QUIC/TLS to the Deskhub host installed on that computer. There is no account, login or Deskhub-operated connection server; demo credentials do not apply. Programs and shell commands run on the host computer.

HOW TO TEST
1. On a computer on the same local network as the iPhone, install Deskhub 9 or newer from https://github.com/manhpham90vn/Deskhub/releases . Supported hosts: Windows 10+ x64, macOS 14+, or a current Linux desktop (glibc 2.35+). On Windows, allow the firewall setup; on macOS, grant Screen Recording and Accessibility when prompted.
2. Open Host, select a display, Terminal and File transfer, then start sharing.
3. Press Show QR code on the computer. In the iOS Client page, tap Scan QR code. Scanning authorizes the device and trusts the host. Alternatively, enter the computer's IP address, compare its fingerprint with the computer's Devices page and tap Trust and connect; then approve the request on the computer. The client retries for two minutes while awaiting approval. A changed host key prevents reconnection.
4. Open Remote desktop, Terminal or File transfer. In Remote desktop, drag to move the pointer, tap to click, double-tap to right-click, hold and drag to select, pinch to zoom and drag with two fingers to scroll. Tap Keys for text and modifier keys. Terminal opens a shell on the computer; File transfer uses the system file/photo pickers.
5. To test receiving, connect FROM the computer TO the phone's displayed address and send a file. Photos/videos are saved using add-only Photos access; other files, or photos when permission is declined, go to Documents in the Files app.
6. To share the phone's screen, tap Start sharing on Host and use the system broadcast sheet. ReplayKit broadcasts the screen and app audio in view-only mode; the microphone is disabled.

PERMISSIONS
• Local Network: connect to the computer.
• Camera: scan pairing QR codes; frames are decoded locally.
• Photos, add only: save received photos/videos.
• Notifications: connection requests and received files.
Session data is encrypted end to end between the devices. We collect no user data; see the privacy policy.
