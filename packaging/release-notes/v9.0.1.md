## ⚠️ Breaking change — update every device

Deskhub 9 speaks a new authentication version, so a 9.x device cannot talk to an 8.x or
7.x one: each refuses the other with "That machine uses an incompatible authentication
version". Update the host and every client together.

Nothing else has to be redone. Keys, allowed devices and trusted hosts all carry over
from 8.0 — no device needs to be let in again. Coming from 7.0.x, follow
[Coming from an older Deskhub](https://github.com/manhpham90vn/Deskhub/blob/main/docs/INSTALL.md#coming-from-an-older-deskhub).

## 🔒 Security

- **A connection request needs a signature.** A host now records a request only after the
  device has signed this connection with the key it shows, so nobody can file a request
  in another machine's name. QR pairing tokens are also checked only after that
  signature.
- **One request per address.** A new request from an address that already has one
  replaces it, so fresh keys from one machine can only overwrite that machine's own row;
  crowding a genuine request off the list of sixteen takes sixteen addresses.
- **Refused connections are closed by the host.** A refused device gets its answer and
  the host hangs up two seconds later, instead of leaving the connection open until the
  device leaves.
- **A deadline for every unauthenticated connection.** Each connection must finish
  signing in within ten seconds, and a host holds at most eight that have not — the rest
  are turned away before any work is done for them.
- **`deskhub://` links ask first.** A pairing link opened from a web page, a message or
  another app now shows the **New host** confirmation, with the fingerprint it names,
  unless that host is already trusted. Compare the fingerprint before accepting. The
  in-app QR scanner still trusts the code directly. On Android, only `deskhub://pair`
  links reach the app.
- **Deny means no.** A device whose request you deny is turned away for the next ten
  minutes instead of filing the same request again a few seconds later. A device that
  was waiting for approval stops at once and says the owner declined.
- **A removed device stays out.** Removing a device under *Devices allowed to connect to
  this machine* while it is connected ends its session with a message saying so. It no
  longer reconnects on its own and leaves a fresh connection request behind.
- **No keystrokes in the Windows logs.** Neither remote control nor the terminal window
  writes key codes or characters to the log any more.
- **Windows Firewall keeps your block rules.** Deskhub used to delete inbound block rules
  for its own exe when it opened the firewall. It now replaces only its own
  *Deskhub (host)* rule; a block rule you made stays, and keeps the host unreachable
  until you remove it.
- **The iOS device key stays out of backups.** The app's config folder, which holds the
  private key, is excluded from iCloud and computer backups.
- **Leftovers cleaned up.** A `passcode=` line in `ui-settings.txt` and the old
  `auth_salt` file are deleted on start, and certificate files a crashed run left behind
  are swept away.
- **Logs.** Log files on macOS and Linux are created readable only by you (`0600`), and
  on every desktop only the ten newest are kept.
- **Hardened builds.** Native code is built with `-fstack-protector-strong` and
  `_FORTIFY_SOURCE=3` (Linux, macOS, iOS; stack protector on Android), full RELRO with
  immediate binding on Linux, and `/sdl` on Windows.

## 🐛 Fixes

- **No more minute-long waits on a failed sign-in.** When a host closes a connection
  before answering — too many attempts, a sign-in that ran past its ten seconds — the
  client now says why at once. A host that never answers is reported within about
  15 seconds instead of 65.
- **iOS shows connection requests while it shares its screen.** A request that arrived
  while the broadcast was running used to stay hidden until the page was rebuilt, so the
  device asking timed out waiting.
- **QR codes expire on phones and tablets too.** iOS and Android now count down the five
  minutes a code is good for, then offer **Generate new QR code**, like the desktops.
  If no code can be made they say so instead of showing nothing.
- **A shell on a host that shares no terminal is refused, not left hanging.**
  `deskhub-cli shell` and `shell --list` used to wait until Ctrl-C; they now say the
  host does not share a terminal.
- **Shells keep their size.** Reattaching to a shell sends the size of your window
  instead of 80×24, and a window resized while the shell was still opening is no longer
  drawn at the old size.
- **Several viewers no longer starve the picture.** The host adjusts the bitrate once a
  second however many viewers report, instead of once per viewer.
- **Resolution changes survive a lossy network.** The message telling a viewer about a
  new size or frame rate is now sent three times, so one lost packet no longer leaves the
  picture cropped or stretched.
- **Clipboard after a host restart.** A viewer that reconnects to a host that was
  restarted picks up its copies again instead of ignoring the first few.
- **Smooth scrolling on Linux and macOS hosts.** A touchpad swipe or smooth wheel no
  longer turns every tiny step into a whole notch and scrolls far past where you meant.
- **Right Alt (AltGr), right Ctrl and right Shift** from a Windows viewer now arrive as
  the right-hand keys on Linux and macOS hosts, so characters such as `@` on German or
  French layouts can be typed.
- **Waiting for approval keeps the host's address.** On every platform, not only
  Android, the Connect fields now hold the host that answered, so pressing Connect after
  the owner approves reaches it even when you came in through a QR code.

- **Fewer audio dropouts.** When a sound packet is lost but the next one has arrived, the
  viewer rebuilds the missing one from the Opus forward error correction the host already
  sends, instead of masking it.
- **Windows installer.** *Launch DeskHub* at the end of setup no longer fails with
  error 740 ("The requested operation requires elevation").
- **macOS Devices page.** A selected row no longer stays selected after its device
  disappears from the table.
- **Wording.** Error messages point at **Devices allowed to connect to this machine**
  (the section's real name), and the client's connection-settings hint now explains how
  to reach a host on another port (`address:port`) instead of describing the removed
  device scan.

## 📦 Packages and building

- **Licence texts ship with every package.** `THIRD_PARTY_NOTICES.md` and the licence
  files of everything bundled — quiche, BoringSSL, the Rust crates, Opus, wxWidgets,
  FFmpeg's LGPL-2.1 where it applies — now come with the Windows installers, the Linux
  `.deb` and `.rpm` (under `/usr/share/doc/deskhub`), the macOS and iOS app bundles and
  the Android app.
- **`make bootstrap`** installs a CMake new enough (≥ 3.25) through pipx when the
  system's is older, accepts an `ANDROID_NDK_VERSION` override, and picks up the pinned
  swiftformat/swiftlint rather than whatever is on `PATH`. Rebuilding the macOS universal
  Opus and quiche libraries is skipped when they are already up to date.
