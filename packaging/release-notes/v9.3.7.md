## Nothing to redo

Deskhub 9.3.7 speaks the same authentication version as every 9.x release, so hosts and
clients on any 9.x release talk to each other and no device has to be let in again.
Coming from 8.x or older, read the
[9.0.1 notes](https://github.com/manhpham90vn/Deskhub/releases/tag/v9.0.1) first: every
device must be on Deskhub 9.

Everything below is on the desktop viewer; the host needs nothing new.

## 🔄 Changes

- **`Esc` reaches the host while in full screen.** On Windows, macOS and Linux, and in
  `deskhub-cli` on Linux, `F11` is now the only key that enters or leaves full screen, which
  reverses the change made in 9.3.6. Pressing `Esc` in full screen sends `Esc` straight to
  the host like any other key, so games, editors and dialogs on the host can use `Esc`
  without leaving full screen first.

## 📦 Packages and building

- **Windows builds retry the wxWidgets download and find Android Studio's JDK.** Configuring
  the Windows desktop app retries downloading the wxWidgets archive on transient GitHub
  download failures, test-only CMake runs skip configuring the Windows desktop app, and the
  Windows `make` rules fall back to the JDK bundled with Android Studio when `JAVA_HOME` is
  not set.
