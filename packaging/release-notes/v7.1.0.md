## ⚠️ Breaking change — update every device

Deskhub 7.1 changes how a device signs in, so a 7.1 device and a 7.0.x device cannot
talk: each tells the other that their versions do not match. Update the host and every
client together.

- **One key per machine.** The key a machine already used as a host (`host_key.pem`)
  is now also the key it signs in with as a client. Fingerprints do not change, so hosts
  you trusted stay trusted — but every client has to be let in **once more**, because
  the key it presents is new. That is now one press of *Approve* or one scan of a QR
  code, not a paste.
- **My keys is gone.** Named client keys, key import and `client_key*.pem` are removed;
  a leftover file is ignored. No certificate is stored any more either: the TLS
  certificate is built in memory each time the port opens, and `host_cert.pem` is no
  longer written.
- **Trust follows the key, not the address.** A trusted host that gets a new address
  connects without asking. A *different* key at a known address is treated as a new
  host: the **New host** dialog appears with a warning naming the machine that used to
  answer there. "This host's key has changed" no longer exists.

## ✨ What's new

- **Connection requests.** A device that connects without being allowed no longer fails.
  The host's Host page lists it under **Connection requests** — name, key fingerprint,
  address — with **Approve** and **Deny**. The device waits and retries on its own for
  two minutes; *Approve* lets it in on its next try and adds its key labelled with its
  name. Requests expire after ten minutes; a host keeps at most sixteen.
- **QR code.** While sharing, press **Show QR code** beside the address list. A phone
  presses **Scan QR code** on its Client page (camera permission is asked for only
  then; frames never leave the device), or any device pastes the link under the code
  into the address field. The code carries the host's addresses, fingerprint, name and
  a one-time token good for five minutes — the device checks it is talking to the
  machine that made the code, trusts it, and is let in at once. Hiding the code, or
  stopping the share, revokes it.
- **Copy public key** on the Devices page copies this machine's one key, labelled with
  its device name. Pasting a key by hand still works.
- **Trusted hosts** show each host's name, fingerprint and the last address it answered
  at.

## 🔌 Connecting in 7.1

1. **Host:** start sharing and press **Show QR code**.
2. **Phone:** Client page → **Scan QR code**, point it at the screen. Done — the phone
   is trusted, allowed and connected.
3. **Any other device:** paste the link under the code into the address field and press
   *Connect*. Or type the host's address, confirm the **New host** fingerprint, and ask
   the host's owner to press **Approve** under *Connection requests*; the device connects
   the moment they do.

Later connections need none of this, at any address the host turns up on.

## 💻 CLI

- New: `share --qr` (prints the QR code and the invite link), `access requests [--json]`,
  `access approve --fingerprint SHA256:…`, `access deny --fingerprint SHA256:…`, and an
  invite link in place of an address for `connect`, `sources`, `shell` and `send`.
  `connect` and friends wait up to two minutes for an *Approve*.
- Changed: `key public` prints this machine's one key (no `--name`);
  `host add ALIAS --address IP[:PORT] --host-key-stdin`; `trust forget` takes a
  fingerprint, alias or last address.
- Removed: `key generate/import/delete/list`, `devices identities/generate/import`,
  `--identity`, `host add --identity`, and exit code `5` ("key changed").

```sh
deskhub-cli share --qr                                # host: show the code
deskhub-cli connect 'deskhub://pair/…'                # client: paste the link, get in at once
deskhub-cli connect 192.168.1.10                      # client: waits for the owner's Approve
deskhub-cli access requests                           # host: who is waiting
deskhub-cli access approve --fingerprint SHA256:…     # host: let one in
```

Two new files live in the config folder: `access_requests` (requests waiting) and
`pairing_tokens` (live QR tokens). Full guide:
[Keys and access](https://github.com/manhpham90vn/Deskhub/blob/main/docs/INSTALL.md#-keys-and-access).
