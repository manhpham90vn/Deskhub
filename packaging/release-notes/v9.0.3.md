## Nothing to redo

Deskhub 9.0.3 speaks the same authentication version as 9.0.1 and 9.0.2, so hosts and
clients on any 9.x release talk to each other and no device has to be let in again. Coming
from 8.x or older, read the [9.0.1 notes](https://github.com/manhpham90vn/Deskhub/releases/tag/v9.0.1)
first: every device must be on Deskhub 9.

The fix below is on the Windows host, so update the Windows machine you connect **to**;
the viewer needs nothing new.

## 🐛 Fixes

- **No more crackle in the sound of a Windows machine.** Watching a Windows host, the
  viewer heard a steady crackle over everything the machine played — and still heard
  sound, crackle included, with the Windows speakers muted. The host padded its sound
  with silence on a timer of its own, even while real sound was arriving, so it cut
  bursts of silence into the middle of the audio and sent about 68 frames a second
  instead of 50; the viewer had to throw away one frame in four to keep up. The host
  now fills in silence only when Windows has actually stopped delivering sound, so the
  stream is back to exactly 50 frames a second and nothing is dropped.
- **Muting a Windows host mutes it for the viewer too.** Windows hands the shared sound
  over before its own mute is applied, so a muted host used to go on sending everything
  it played. The host now checks the speakers' mute and sends silence while they are
  muted.

## 📦 Packages and building

- **Windows bootstrap finishes on its own.** `scripts/bootstrap.ps1` adds NASM to the
  user `PATH` itself instead of asking you to, and no longer stops when winget reports a
  tool that is already installed but not yet on the current terminal's `PATH`.
