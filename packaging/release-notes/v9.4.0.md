## Nothing to redo

Deskhub 9.4.0 speaks the same authentication version as every 9.x release, so hosts and
clients on any 9.x release talk to each other and no device has to be let in again.
Coming from 8.x or older, read the
[9.0.1 notes](https://github.com/Bitfaring/Deskhub/releases/tag/v9.0.1) first: every
device must be on Deskhub 9.

## ✨ New

- **Mute the host's sound from the viewer.** Every viewer that plays the host's sound now
  has a **Mute sound** button: beside **Show my cursor** on Windows and Linux, in the
  button bar on macOS, and in the session controls on Android and iOS. It silences only
  that window; **Unmute sound** brings the sound back at once, in step with the picture.
  ([#161](https://github.com/Bitfaring/Deskhub/issues/161))

## 🔄 Changes

- **Deskhub moved to [github.com/Bitfaring/Deskhub](https://github.com/Bitfaring/Deskhub).**
  Old links redirect. The apt repository moved with it and the old address no longer
  answers, so Ubuntu and Debian machines that installed from it need the new source once:

  ```sh
  sudo install -d /etc/apt/keyrings
  curl -fsSL https://bitfaring.github.io/Deskhub/apt/deskhub.gpg | sudo tee /etc/apt/keyrings/deskhub.gpg >/dev/null
  echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/deskhub.gpg] https://bitfaring.github.io/Deskhub/apt stable main" \
    | sudo tee /etc/apt/sources.list.d/deskhub.list
  sudo apt update
  ```

  The Homebrew tap is now `bitfaring/tap`: `brew install --cask bitfaring/tap/deskhub`.
