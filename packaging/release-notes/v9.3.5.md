## Nothing to redo

Deskhub 9.3.5 speaks the same authentication version as every 9.x release, so hosts and
clients on any 9.x release talk to each other and no device has to be let in again.
Coming from 8.x or older, read the
[9.0.1 notes](https://github.com/manhpham90vn/Deskhub/releases/tag/v9.0.1) first: every
device must be on Deskhub 9.

Everything below is on the machine you connect **from**; the host needs nothing new.
**`F9` no longer locks the mouse**, and neither `F9` nor `F11` reaches the host any more.
If a program on the host needs either key, use 9.3.4 as the viewer for now.

## ✨ New

- **Full screen on every desktop viewer.** On Windows, macOS and Linux, press `F11` or
  click **Full screen (F11)** above the picture, and the remote screen fills the whole
  monitor with the button bar hidden. Press `F11` again to get the window back. It works in
  view-only sessions too. On a Mac keyboard whose function keys control brightness and
  volume, press `fn`+`F11`.
- **One pointer instead of two.** The host already draws its own pointer into the picture,
  so a viewer used to show two arrows on top of each other, the host's trailing slightly
  behind the viewer's. While you control the host, the viewer now hides its own pointer
  over the picture, and only the host's is left. Press `F9` or click
  **Show my cursor (F9)** to bring the viewer's pointer back, and **Hide my cursor (F9)** to
  hide it again. The viewer's pointer still shows over the button bar, over the black bars
  beside the picture and outside the window. In a view-only session nothing changes: there
  is no such button, and the viewer's pointer is always shown.

## 🔄 Changes

- **The mouse lock is gone.** `F9` used to lock the mouse inside the viewer window and send
  raw movement to the host, for games. It now shows and hides the viewer's pointer instead,
  as described above, and `Esc` goes to the host like any other key. A 9.3.5 host still
  accepts that raw movement from an older viewer, so a 9.3.4 viewer can keep using its
  lock.
- **The window title is shorter.** It no longer ends with *Press F9 to lock mouse*; it
  shows the source and the live status only. A view-only session still says so.
- **The Linux viewer has no *Disconnect* button.** Close the window to end the session,
  as on Windows. The Mac viewer keeps its button.

## 📦 Packages and building

- **`deskhub-cli` on Linux no longer links libXfixes.** Its remote-screen window hides the
  pointer with a blank X cursor instead, so building it needs only `libx11-dev` of the two.
