## Nothing to redo

Deskhub 9.1.0 speaks the same authentication version as every 9.0 release, so hosts and
clients on any 9.x release talk to each other and no device has to be let in again. Coming
from 8.x or older, read the [9.0.1 notes](https://github.com/manhpham90vn/Deskhub/releases/tag/v9.0.1)
first: every device must be on Deskhub 9.

What is new is on the Windows host, so update the Windows machine you connect **to**; the
viewer needs nothing new.

## ⚠️ Windows: install with the setup file

- **The setup now installs DeskHub for every user, under `Program Files`,** and asks for
  administrator rights to do it. It removes a DeskHub that an earlier version installed for
  your user alone, and moves *Start Deskhub when you log in* to the new location. Your
  settings, keys and allowed devices stay where they are.
- **winget users:** `winget upgrade ManhPham.Deskhub` does the same.
- **The portable `deskhub-v9.1.0-windows.exe` still works,** but without the new feature
  below. While sharing, it says so on the Host page and points you to the setup file.

## ✨ New

- **Viewers can answer Windows permission prompts and the lock screen.** Until now, when
  an installer on the shared PC asked *"Do you want to allow this app to make changes to
  your device?"*, or the PC was locked, viewers saw a frozen picture and their clicks and
  keys went nowhere. The person at the PC had to answer it. Now viewers see that screen
  and can click **Yes**, type a password, or use the Ctrl+Alt+Del screen when someone at
  the PC has opened it, and the picture
  returns to the normal desktop when it closes. This works through a small system
  service, *DeskHub Secure Desktop*, which the setup installs. It does nothing until
  DeskHub shares a screen, and it opens no network connection of its own.
- **Mind the lock screen.** Because viewers can now type into the lock screen, anyone you
  share with who knows the Windows password can unlock the PC. If that matters, stop
  sharing before you walk away instead of only locking.

## 📦 Packages and building

- **New `DeskhubService.exe`** is built beside `Deskhub.exe` and shipped in the Windows
  installer, which registers it with `--install` and removes it with `--uninstall`. The
  installer check in CI now also verifies that the service is installed, running, and
  gone after uninstall.
- **winget:** the `ManhPham.Deskhub` installer is now per-machine. Set the manifest's
  scope to `machine` in the pull request komac opens for this release.
