## Nothing to redo

Deskhub 9.3.6 speaks the same authentication version as every 9.x release, so hosts and
clients on any 9.x release talk to each other and no device has to be let in again.
Coming from 8.x or older, read the
[9.0.1 notes](https://github.com/manhpham90vn/Deskhub/releases/tag/v9.0.1) first: every
device must be on Deskhub 9.

**Windows hosts: Deskhub now turns off firewall rules that block it.** When you share, the
app disables every enabled inbound Windows Firewall block rule aimed at `Deskhub.exe`, which
reverses the change made in 9.0.1. If you blocked Deskhub on purpose, make that rule target
the port or the address instead of the program, and Deskhub leaves it alone.

## ✨ New

- **`Esc` leaves full screen.** On Windows, macOS and Linux, and in `deskhub-cli` on Linux,
  `Esc` now returns a full-screen viewer to its window, just as `F11` does. In a window
  `Esc` still goes to the host as before; while full screen it stays with the viewer, so
  leave full screen first when a program on the host needs it.

## 🔄 Changes

- **The Windows viewer's buttons look at home.** *Full screen (F11)* and
  *Show my cursor (F9)* are flat, rounded buttons in the system font on a dark bar, each as
  wide as its label, and they light up under the pointer instead of being two grey
  150-pixel boxes on black.
- **The Mac viewer has no *Disconnect* button.** Close the window to end the session, as
  on Windows and Linux. Its button bar no longer repeats the host's address, and neither
  does the connection window.

## 🐛 Fixes

- **A Windows host can be reached over a network Windows had blocked it on.** The first
  time Deskhub listens, Windows asks *Allow this app?*; leaving a network type unticked
  there adds a block rule for Deskhub on that type, and a block rule beats Deskhub's own
  *Deskhub (host)* allow rule. A host whose VPN adapter — Tailscale, for one — counts as a
  private network could then not be reached over the VPN at all, while the LAN worked.
  Sharing now disables those rules. They are turned off, not deleted, so they stay
  visible in Windows Defender Firewall. The *DeskHub Secure Desktop* service does the same
  for its own program. The [privacy policy](https://github.com/manhpham90vn/Deskhub/blob/main/PRIVACY.md)
  moves to version 2.18 to say so.
