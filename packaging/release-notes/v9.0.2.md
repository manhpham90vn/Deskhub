## Nothing to redo

Deskhub 9.0.2 speaks the same authentication version as 9.0.1, so hosts and clients on
either release talk to each other and no device has to be let in again. Coming from 8.x
or older, read the [9.0.1 notes](https://github.com/manhpham90vn/Deskhub/releases/tag/v9.0.1)
first: every device must be on Deskhub 9.

## 🐛 Fixes

- **Stop sharing no longer freezes the Windows app on NVIDIA machines.** Pressing
  **Stop sharing** — from the button, from the tray menu, or by quitting while a share
  was running — left the window hung for good, and the process had to be ended from Task
  Manager. When the share stopped, the NVENC encoder was asked to hand back one more
  frame after the end-of-stream flag, and the driver waited forever for a frame that had
  never been submitted. The encoder now reads a frame back only when it actually holds
  one. Machines that encode through Media Foundation (Intel and AMD graphics) were not
  affected.

## 📱 Android

- **Deskhub is on Google Play.** The app has left the testing track: install it from
  [Google Play](https://play.google.com/store/apps/details?id=com.manhpham.deskhub) with
  no tester group to join. The apk on the Releases page is still there for devices without
  Play. The install guide no longer describes the beta steps.

## 📦 Packages and building

- **Android crash reports are readable.** Builds upload full native debug symbols to
  Google Play, so a crash in the native code shows function names instead of addresses.
- **Android dependencies.** Gradle 9.8.0, androidx.core 1.19.1 and ZXing 3.5.4.
