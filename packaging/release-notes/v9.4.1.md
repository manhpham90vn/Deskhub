## Nothing to redo

Deskhub 9.4.1 speaks the same authentication version as every 9.x release, so hosts and
clients on any 9.x release talk to each other and no device has to be let in again.

## ✨ New

- **The Host tab remembers what you share.** On Windows, macOS and Linux the
  **Terminal** and **File transfer** tick boxes keep the choice you last made, across
  launches, instead of coming back ticked every time.
  ([#165](https://github.com/Bitfaring/Deskhub/issues/165))

## 🔄 Changes

- **Only the sessions a host offers are shown.** After connecting, the **Terminal** and
  **File transfer** buttons appear only when the host shares them, on every client,
  instead of sitting there greyed out.
  ([#165](https://github.com/Bitfaring/Deskhub/issues/165))
