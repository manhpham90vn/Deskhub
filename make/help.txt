Deskhub - no platform is built by default, name the one you want:

  Build / release / run:
    make build-windows   release-windows   run-windows     needs Windows + MSVC
    make build-macos     release-macos     run-macos       needs macOS + Xcode
    make build-linux     release-linux     run-linux       needs Ubuntu + the -dev packages
    make build-ios       release-ios       run-ios         needs macOS + Xcode, Simulator
    make build-android   release-android   run-android     needs the Android SDK/NDK, adb

    The desktop apps take no flags - everything is chosen on their four pages;
    run-windows and run-linux still pass ARGS="..." through.
    macOS: MACOS_SIGN=adhoc|developerid, MACOS_TEAM=..., MACOS_XCARGS="..."
    iOS:   IOS_DEVICE=<simulator udid> for run-ios

  Command line client - Linux, Windows and macOS, no GUI toolkit:
    make build-cli       release-cli       run-cli         one deskhub-cli binary
                         run-cli takes ARGS="host list", ARGS="sources 192.168.1.10", ...
                         on Linux they build ffmpeg-min first
    make cli-smoke       host + viewer + a remote shell over loopback, headless

  Shared CMake tree - core + platform + the current OS client:
    make debug           configure + build the debug preset
    make release         configure + build the release preset
    make quiche          build the QUIC library (third_party/quiche) for the host target;
                         without it nothing can share or connect
    make opus            build the Opus audio codec (third_party/opus) for the host target;
                         without it a share carries no sound
                         debug, release, every build-*/release-*/CLI target, test, every
                         test-* and lint-tidy build both first; a failed build stops make

  QUIC library and Opus for the cross-compiled apps - each build-* target runs its own first:
    make quiche-android  arm64-v8a + x86_64 (needs the NDK; cargo-ndk outside Windows)
    make quiche-ios      iOS device + Simulator
    make quiche-macos    arm64 + x86_64, lipo'd into macos-universal
    make opus-android    arm64-v8a + x86_64 (needs the NDK)
    make opus-ios        iOS device + Simulator
    make opus-macos      arm64 + x86_64, lipo'd into macos-universal

  Tests:
    make test              build core_tests and run it offline
    make test-platform     build platform_tests and run it (loopback sockets, no remote peer)
    make test-integration  host + viewer over loopback (fake codecs) + golden wire bytes
    make test-all          all three suites, core first
    make test-ctest        the same tests through CTest, as CI runs them
    make test-asan         all three suites under ASan + UBSan (Linux/macOS)
    make test-tsan         all three suites under ThreadSanitizer (Linux/macOS)
    make perf-build        build core_perf + platform_perf (release preset) without running them
    make test-perf         measure the hot core + QUIC paths in a release build (cost, allocations, scaling)
    make perf-baseline     record out/perf/*.txt baselines so test-perf can report drift per row
    make fuzz              libFuzzer + ASan over the parsers, sessions, key/access-list/invite
                           text and the QR encoder (clang, Linux/macOS, FUZZ_SECONDS=N)
    make fuzz-coverage     which core lines the fuzz corpus reaches (clang + llvm-cov, Linux/macOS)
    make coverage          core coverage report via clang + llvm-cov

  Style - C++ + Kotlin + Swift, or one at a time:
    make format          apply formatting in place
    make lint            check without fixing, what CI enforces (includes lint-dead)
    make format-cpp      lint-cpp / format-kotlin / lint-kotlin / format-swift / lint-swift
    make lint-dead       unused C++ functions, FFI functions, string ids, Kotlin code
    make lint-dead-swift unused Swift code via Periphery (macOS + Xcode)
    make lint-tidy       clang-tidy over core/src + platform/src, the same gate CI runs
                         (builds quiche + opus first)

  Distribution:
    make dist-macos      dmg signed with Developer ID + notarized + stapled
                         (ASC_KEY_P8, ASC_KEY_ID, ASC_ISSUER_ID + a Developer ID identity)
    make verify-macos    check that Gatekeeper accepts the build just produced
    make dist-linux      Separate app and CLI Linux .deb + .rpm packages; each ships the uinput udev rule

  Developer tools:
    make icons           regenerate every client icon from assets/icon_1024.png
    make quic-smoke      standalone QUIC client+server against the quiche static library
    make opus-smoke      standalone encode/decode round-trip against the opus static library
    make screenshots     macOS: recapture the store screenshots on the iPhone/iPad
                         simulators, the Android emulators and the macOS app, then
                         refresh docs/imgs (ARGS="ios android macos readme" for a subset)

  Setup:
    make bootstrap                  install every dev dependency for this OS
    make setup-linux-permissions    Ubuntu host role: udev rule + 'input' group
    make reset-macos-permissions    macOS: clear the TCC grants of com.deskhub.macos and
                                    com.deskhub.macos.debug when the local build and a
                                    downloaded build conflict (ARGS="--purge")
    make ffmpeg-min                 Ubuntu: build the static minimal FFmpeg (auto-run by
                                    build-linux, release-linux and the CLI targets)
    make clean                      remove out/

  Every target is documented in full at the top of the Makefile.
